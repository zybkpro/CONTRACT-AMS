## 架构现实

两边都是 **Electron 桌面端 + 本机 api-server**，不是纯 Web SaaS。

因此：

- 「每次启动联网 verify」——桌面端已基本具备，需收紧弱网与局域网路径  
- 「Token 完全不进安装包」——单机桌面成本高，需中转服务才能真正落地  
- 「关键功能上云」——台账类本地软件可后置（P2）

---

## 现状对照

| 建议 | IT-AMS | CONTRACT-AMS |
|------|--------|--------------|
| 启动联网 verify | 桌面 `getStatus()` 已做 | 桌面已做；**局域网/H5 走 `getLocalStatus()` 不联网** |
| Token 不进安装包 | ❌ 写死在 `license.js` 并打进包 | 同左 |
| machine_id 难伪造 | ❌ 本地 `randomUUID` 文件 | 同左 |
| 关键能力在线票据 | ❌ 业务全在本地 sqlite | 同左 |

## 分档改造（按优先级）

### P0（必做，工作量小，性价比高）

#### ① 收紧弱网放行（两边 `license.js`）

**现状：** 断网且本地 `expiresAt` 未过期 → 直接 `activated: true`。

**建议：**

- 在 `license.json` 增加 `lastOnlineOkAt`，仅远程 `verify` 成功时更新  
- 连续断网超过 N 天（建议 3 或 7 天）→ **强制锁定**，提示联网校验  
- 弱网临时放行时，UI 明确提示「临时离线模式，请尽快联网」

伪逻辑：

```js
function offlineGraceOk(lic, maxOfflineDays = 3) {
  if (!localStillValid(lic)) return false
  const last = Date.parse(lic.lastOnlineOkAt || lic.verifiedAt || 0)
  if (!Number.isFinite(last)) return false
  return Date.now() - last < maxOfflineDays * 86400000
}
// getStatus catch 分支：offlineGraceOk(lic) 才放行，否则锁定
```

#### ② CONTRACT 局域网校验（CONTRACT 重点）

`packages/api-server/core.js` 里局域网/H5 使用 `getLocalStatus()`，**不调 CAPTCHA**。

改法二选一：

- **A**：`/api/license/status` 也走 `getStatus()`（会联网，稍慢，最严）  
- **B**：保留本地快路径，但桌面主机**后台定时**（如每小时）或每次打开业务页触发 `verify`，失败则全员锁定  

推荐先做 **B**，体验更好；对盗版更敏感再上 A。

#### ③ 正式包禁止跳过授权

- 生产构建禁止 `ITAMS_SKIP_LICENSE=1` / `CONTRACTAMS_SKIP_LICENSE=1`  
- 打包脚本检测：正式包若开启 skip → 构建失败  

#### ④ Token：至少不要源码明文写死

完全「不进包」见 P1 中转；P0 先做到：

1. 删除 `DEFAULTS.apiToken` 里的明文默认值（或仅允许开发环境）  
2. 正式包必须通过环境变量 / 构建注入提供 Token  
3. CAPTCHA 服务保持失败限流  

| 项目 | 环境变量 |
|------|----------|
| IT-AMS | `ITAMS_LICENSE_API_TOKEN`、`ITAMS_LICENSE_API_BASE` |
| CONTRACT-AMS | `CONTRACTAMS_LICENSE_API_TOKEN`、`CONTRACTAMS_LICENSE_API_BASE` |

### P1（推荐，明显抬高成本）

#### ⑤ machine_id 加固（两边 `getMachineId()`）

**现状：** `crypto.randomUUID()` 写入 `data/machine_id` → 拷贝该文件 + `license.json` 即可搬家。

**建议：**

```text
machine_id = hash(
  首次安装生成的 UUID（落盘，保证稳定）
  + 可选：主机名 / 主板 UUID / MAC（取得到就加）
)
```

规则：

- 重启后尽量不变  
- 启动时重算指纹；与 `license.json` 内 `machineId` 不一致 → 视为换机，要求重新激活  
- 不要只依赖可被随意编辑的单个明文 ID 文件作为唯一依据  

#### ⑥ Token 中转（真正「不进安装包」）

需你有一台可控的在线小服务：

```text
桌面软件 ──HTTPS──► 你的中转 API（校验产品签名 / 设备指纹）
                      │
                      └── X-API-Token ──► CAPTCHA_SYS /activate|/verify
```

改动：

- `license.js` 的 `remoteCall` 改为请求中转 URL，**请求不再带 CAPTCHA Token**  
- Token 只存在中转服务器环境变量  
- 中转可做：按 `machine_id` 限流、黑名单、盗版统计  

配置示例：

- `ITAMS_LICENSE_RELAY_URL`  
- `CONTRACTAMS_LICENSE_RELAY_URL`  

#### ⑦ 业务 API 门禁（两边 `http.js` / CONTRACT 的 `core.js`）

**现状：** 主要靠前端门禁，改渲染层即可绕过。

**建议：** 除 `health` / `license` / `auth` 外，业务接口统一校验授权：

- 调用 `license.getStatus()`（或带 5～15 分钟缓存的结果）  
- 失败返回 HTTP 403  
- 避免每个请求都打 CAPTCHA（用内存缓存 `lastVerifyOk`）  

这样「只改 UI 跳过激活页」不够用。

---

### P2（理想，成本高，可后置）

#### ⑧ 关键能力上云或在线短期票据

导出、打印、同步、高级报表等需中转签发的短期 ticket。  
本地改 `activated=true` 也打不开这些能力。

台账类本地产品做到 **P0 + P1** 通常已够售卖；SaaS 化后再上 P2。

## 改哪些文件

### IT-AMS

| 文件 | 改什么 |
|------|--------|
| `packages/api-server/license.js` | 弱网天数、`lastOnlineOkAt`、加固 machine_id、去硬编码 Token、可选中转 URL |
| `packages/api-server/http.js` | 业务路由授权中间件（403） |
| `scripts/package-*.js` / `scripts/lib/*` | 正式包禁 SKIP；注入 Token 或 Relay |
| `src/App.vue`、激活/设置相关组件 | 离线提示、到期/套餐展示 |

### CONTRACT-AMS（比 IT-AMS 多一项）

| 文件 | 改什么 |
|------|--------|
| 同上 license / http / 打包 / UI | 与 IT-AMS 同步 |
| `packages/api-server/core.js` | 局域网不要长期只信 `getLocalStatus()` |
| 试用 `trial.json` 相关逻辑/文案 | 与付费「七天卡」区分开 |

**建议：先改 IT-AMS 的 `license.js`，再同步到 CONTRACT-AMS**（两边高度同源）。

## 推荐落地顺序

| 阶段 | 内容 | 预估 |
|------|------|------|
| 第 1 步 | P0：弱网限期 + 去硬编码 Token + 正式包禁 skip | 0.5～1 天 |
| 第 2 步 | P0：CONTRACT 局域网校验策略（A 或 B） | 0.5 天 |
| 第 3 步 | P1：machine_id 加固 + 业务 API 403 | 1～2 天 |
| 第 4 步 | P1：有云服务器后再做中转 API | 按基础设施另计 |

## 预期效果

| 做完 | 效果 |
|------|------|
| P0 + P1 | 偷码乱用、拷贝数据目录、只改前端跳门禁、长期离线蹭用 → 明显变难 |
| 仍防不住 | 会直接改 `api-server` 源码/打包产物的人 |
| 对售卖 | **够用**；不要追求「不可破解」 |

## 验收清单（改完自测）

- [ ] 无 Token / 错误 Token → 激活失败  
- [ ] 正常码激活成功，`license.json` 含 `planType` / `expiresAt` / `lastOnlineOkAt`  
- [ ] 每次启动（桌面）会远程 verify  
- [ ] 断网未超宽限期 → 临时放行 + 有提示  
- [ ] 断网超过宽限期 → 锁定  
- [ ] 远程返回已过期/已作废 → 锁定  
- [ ] 拷贝别人的 `machine_id`+`license.json` 到新机 → 失败或要求重激活（加固后）  
- [ ] 未授权时调业务 API → 403（P1）  
- [ ] 正式安装包无法用 SKIP 绕过  
- [ ] CONTRACT 局域网客户端在主机锁定后也无法继续用
