# 合同管理系统功能介绍：把散落的合同，变成一本看得清的台账

> 面向中小企业商务、项目与财务协同人员的本地化合同管理工具——从起草、审批、签署，到履约、收付款、归档，一份合同的全生命周期都在这里。

## 一、为什么需要它

很多公司的合同是这样的：对外销售合同在销售手里，对内采购/外包合同在项目经理手里，扫描件散落在网盘和微信，到期续约靠人记，回款进度靠问。结果就是——**对内对外对不上，项目视角看不全，到期和回款全靠人盯**。

合同管理系统（CONTRACT-AMS）要解决的正是这件事：用**一套台账**统一管理对内、对外合同，以「方向 / 类型」字段区分，而不是拆成两套系统。这样一个项目下的销售合同、采购合同、补充协议能一眼看全。

它做的是合同**全链路管理**——起草 → 审批 → 签署 → 履约 → 收付款 → 归档/到期，而不仅仅是一个存放扫描件的"文件柜"。

![合同台账主界面](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/1.webp)

*台账首页：顶部 KPI 摘要 + 多视图切换 + 可筛选的合同列表，合同状态、到期提醒、相对方脱敏一目了然。*

## 二、核心功能一览

### 1. 一份台账，管好对内对外所有合同

新建合同时，填写编号、名称、方向（对内/对外）、类型、关联项目、相对方、金额、签订日/起止日等信息。编号支持按规则自动生成（如对外 `XS20260001`、对内 `CG20260001`），流水按前缀+年份递增，不用手工编号。

![新增合同](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/2.webp)

*新增合同表单：编号自动生成，方向切换时类型选项自动过滤。*

已录入的合同可以随时编辑，字段变更会自动写入生命周期日志——谁在什么时候把金额从多少改到多少，都有据可查。

![编辑合同](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/3.webp)

*编辑合同：修改即留痕，无需额外操作。*

### 2. 按项目看合同，关系一目了然

项目视图用卡片展示每个项目的关联合同数量、合同总金额和起止时间。比如"智慧园区一期"下挂着 4 份合同：软件外包、硬件采购、平台建设主合同及其补充协议——既看得到单份，也看得到全局。还可以直接从项目卡片「为此项目建合同」，不用再回头找项目下拉框。

![项目视图](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/8.webp)

*项目视图：一个项目下的多份对内、对外合同集中呈现。*

### 3. 合同详情抽屉，六大维度看透一份合同

点开任意合同，右侧抽屉按「基本信息 / 文件与版本 / 履约节点 / 收付款 / 审批 / 生命周期日志」六个 Tab 组织信息。基本信息里，方向、类型、金额、起止日、自动续约、终止条件、相对方等关键字段集中呈现。

![合同详情-基本信息](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/4.webp)

*合同详情：六个 Tab 覆盖一份合同的全维度信息。*

几个实用细节：

- **文件与版本**：正文可标记，替换时自动升版（v1、v2…）并保留历史，每次变更说明"谁、何时、换了哪一版"。
- **履约节点**：交付、验收、质保等里程碑用时间轴展示，实际完成日晚于计划日会自动标记"逾期"。
- **轻量审批**：草稿提交进入"审批中"，管理员可通过或驳回；驳回必须填意见。金额达到阈值（如 ≥10 万一级、≥50 万二级）才需相应层级审批，小额可直接签署。
- **生命周期日志**：创建、变更、状态流转、文件替换、查看、下载、收付款登记、归档——全部只追加、不可篡改。

### 4. 收付款：计划 vs 实际，差额看得见

很多合同管理到这里就断了——签完就没人跟踪钱。系统把「收付款计划」和「实际流水」分开记录：计划拆成期次（如首付/进度款/尾款），实际登记每一笔到账，每期自动算差额，未收、部分到账高亮提醒。

![合同详情-收付款](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/5.webp)

*收付款：计划金额、已收/已付、未收/未付、回款率汇总，下方是计划与实际流水。*

合同维度能看到合同金额、计划合计、已收/已付和余额；全局看板则汇总应收未收、应付未付和回款率。项目经理只能看自己负责项目的合同，财务可以登记收付款但不能删除合同——权限跟着账号走。

### 5. 看板与到期提醒：风险提前看见

顶部 KPI 条展示合同总数、在签金额、履约中、本月到期、已过期未处理、应收未收、应付未付、回款率。看板页用饼图看对内/对外占比，用柱状图看状态分布，再配「即将到期 Top 10」和「已过期未处理 Top 10」两张清单。

![看板统计](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/7.webp)

*看板：对内/对外占比、状态分布，以及即将到期与逾期清单。*

台账行会直接标注"5 天后到期"或"已过期 20 天"，提醒窗口（30/15/7 天）可配置。自动续约标记和终止条件备注也一并展示，辅助判断是否需要处理。

### 6. 灵活设置，适配不同公司的规则

系统设置提供合同类型字典（按方向过滤，被引用的类型不可删）、编号前缀、金额口径、审批阈值、提醒天数、归档策略、脱敏规则和登录密码修改。换一家公司用，不用改代码，改设置即可。

![系统设置](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/6.webp)

*系统设置：合同类型字典，可自定义类型及其适用方向。*

## 三、还有这些设计

- **权限与脱敏**：账号登录后，角色（管理员/商务/项目经理/财务）决定权限；相对方账号、信用代码、电话等敏感字段按规则脱敏显示与导出。当前版本仅开放超级管理员登录，其余角色可按需开启。
- **导入导出**：按模板批量导入合同，失败行回报行号和原因；当前筛选结果可导出 Excel。
- **归档只读**：履约完成或终止后归档为只读态，保留文件与日志；仅管理员可解档，且留痕。
- **桌面 + 局域网 + 手机**：桌面应用把数据放在本机 SQLite，同一局域网内的手机可通过 H5 查阅合同、登记收付款，三端共用同一份数据和业务逻辑。
- **本地数据**：数据留在自己机器上，不依赖云服务商；支持备份与还原。

## 四、适合谁用

- 同时跑多个项目、每个项目既有销售合同又有采购/外包合同的中小企业；
- 合同散落在个人电脑、网盘和微信，想统一台账的商务与行政部门；
- 需要跟踪回款进度、到期续约，又不想上重型 ERP / 法务系统的团队。

> 它不是要做完整的法务知识库或复杂 BPM 流程引擎，而是把"合同这件事"管清楚：找得到、看得全、跟得住、留得下痕。

## 五、结语

合同管理的价值，不在于把文件存起来，而在于让每一个项目的合同关系、金额、履约和回款状态随时可见。**一份台账看清对内对外，一个项目看全所有合同，一份合同看透全生命周期**——这是合同管理系统想做的事。
