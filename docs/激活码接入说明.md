# CONTRACT-AMS 激活码接入说明

对接集中部署的激活码管理系统（`CAPTCHA_SYS`），与 IT-AMS 同源。桌面主机启动时校验授权；未激活则进入激活页，可扫码添加客服领取体验码或购买正式码。

> 开发调试可用 `CONTRACTAMS_SKIP_LICENSE=1` 跳过门禁（见文末）。

## 行为摘要

| 场景 | 行为 |
|------|------|
| 首次启动 / 无本地授权 | 全屏激活页，不可关闭 |
| 输入激活码 | 主进程带 Token 调用 `POST /api/v1/activate`，成功写入 `data/license.json` |
| 日常启动 | 调用 `POST /api/v1/verify`；失败则锁定并提示 |
| 弱网 | 本地 `expiresAt` 未过期可短暂放行，并 toast 提示尽快联网 |
| H5 扫码端 | 不单独激活，跟随主机数据（仅需局域网访问口令） |
| 设置 → 授权激活 | 查看套餐 / 到期 / 机器码，可重新输入激活码 |

客服微信二维码：`src/assets/wechat-cs.png`（与 IT-AMS 同源 OSS）。

## 配置

默认指向生产激活码服务：

| 项 | 默认 | 环境变量覆盖 |
|----|------|----------------|
| API 根地址 | `https://www.zybkpro.top/captcha` | `CONTRACTAMS_LICENSE_API_BASE` |
| API Token | `ZYBKPROTOPCAPTCHA2026` | `CONTRACTAMS_LICENSE_API_TOKEN` |
| 客服二维码 | 同源 OSS | `CONTRACTAMS_LICENSE_WECHAT_QR` |
| 超时(ms) | 12000 | `CONTRACTAMS_LICENSE_TIMEOUT_MS` |
| 跳过校验（仅开发） | 关 | `CONTRACTAMS_SKIP_LICENSE=1` |

**重要：** 产品侧 Token 必须与激活码服务 `.env` 中的 `API_TOKEN` 完全一致。

本地调试跳过门禁：

```bash
CONTRACTAMS_SKIP_LICENSE=1 npm run electron
# 或独立服务模式
CONTRACTAMS_SKIP_LICENSE=1 npm run server
```

## 本地文件

| 文件 | 说明 |
|------|------|
| `data/machine_id` | 本机机器码（首次生成 UUID 并落盘） |
| `data/license.json` | 本地授权缓存（code / planType / expiresAt 等） |

## 相关代码

- `packages/api-server/license.js` — 机器码、激活、校验（环境变量前缀 `CONTRACTAMS_*`）
- `apps/desktop/main.js` / `preload.js` — IPC `license:*`
- `src/components/ActivationDialog.vue` — 激活页 UI（复用 IT-AMS）
