# 合同管理系统 · 安装与兼容性说明（V1.2）

## 系统支持矩阵

| 系统 | 支持情况 | 安装包 |
|------|---------|--------|
| Windows 10 / 11（64 位） | ✅ 主推 | `合同管理系统-Windows-1.2.0-绿色版.zip` |
| Windows 10 / 11（32 位） | ✅ 支持 | `合同管理系统-Windows32位-1.2.0-绿色版.zip` |
| Windows 7 / 8（64/32 位） | ⚠️ 兼容版 | `合同管理系统-Windows*-1.2.0-Win7兼容版.zip` |
| macOS（Apple Silicon / M 系列） | ✅ 支持 | `合同管理系统-macOS-arm64-1.2.0.zip` |
| macOS（Intel） | ✅ 支持 | `合同管理系统-macOS-x64-1.2.0.zip` |

## Windows 常见问题

### 1. 提示"不是有效的 Win32 应用程序"

原因：程序基于 Electron 33，**不支持 Windows 7/8**。请下载带 `Win7兼容版` 字样的安装包（基于 Electron 22.3.27，最后支持 Win7 的分支）。

### 2. 双击后什么也不显示，但任务管理器里有进程

原因：多为显卡硬件加速 / 远程桌面 / 虚拟机环境导致的渲染失败。解决方法（按顺序试）：

1. 解压目录里找到 **`安全模式启动.bat`**，双击运行（等效禁用 GPU 加速）；
2. 仍不行：确认已完整解压（不要直接在 zip 里双击运行）；
3. 查看数据目录的 `app.log`（Win 绿色版在 exe 同级的 `data/app.log`，或 `%APPDATA%/contract-ams/data/app.log`），里面记录了启动各阶段和失败原因。

### 3. 启动诊断日志

V1.2 起主进程会把关键步骤写入 `data/app.log`：启动版本/系统、数据库初始化、窗口渲染、页面加载失败、渲染进程崩溃、窗口 20 秒未显示的警告。反馈问题时附上此日志可快速定位。

## macOS 安装

1. 解压 zip；
2. 先运行一次 `mac-first-run.sh`（移除隔离属性、补可执行位）；
3. 双击 `.app` 打开。若需生成 `.dmg`，运行 `make-dmg.sh`。

## 数据与升级

- 覆盖安装不会丢数据：数据都在 `data/` 目录（与程序同级，或打包版在用户数据目录）。
- 升级前建议先在设置里做一次备份；V1.2 支持从备份 zip 一键恢复。
- 卸载/重装若保留 `data/` 目录，授权码仍有效；删除 `data/` 会导致机器码变化，需联系客服解绑。

## 开发者构建

```bash
npm run package:win       # Win10/11 x64 绿色版
npm run package:win32     # Win10/11 32 位
npm run package:win7      # Win7 兼容版 x64（Electron 22）
npm run package:win7-32   # Win7 兼容版 32 位
npm run package:mac       # macOS x64 + arm64
```
