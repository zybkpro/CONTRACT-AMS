# 合同管理系统

## 核心功能

### 1. 一屏看清合同家底

深色台账看板：顶部 8 个 KPI（合同总数、在签金额、履约中、本月到期、已过期未处理、应收未收、应付未付、回款率），下面是可以按方向、状态、项目筛选的合同列表。打开第一屏就知道公司现在有多少合同、多少钱在签、哪几份快到期、还有多少款没收回来。

![合同台账主界面](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/1.webp)

### 2. 对内对外，一本台账管完

这是当初做它的主要理由。很多公司销售合同在销售手里、采购外包合同在项目手里，文件散在网盘和微信，对内对外根本对不上。这套系统里，对内（采购、外包、劳动补充）和对外（销售、框架、NDA）共用一张表，只用「方向 / 类型」区分。新建时编号自动生成——对外 XS20260001、对内 CG20260001，不用手工编号。

![新增合同表单](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/2.webp)

台账里点任意一行就能编辑，字段变更自动写日志，谁在什么时候把金额从多少改到多少，翻记录就行，不用另外开表对。

![编辑合同表单](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/3.webp)

### 3. 按项目看合同，一项目多合同不糊涂

项目视图用卡片列出每个项目挂了几份合同、合同总金额、起止时间。比如"智慧园区一期"下面挂着 4 份：软件外包、硬件采购、平台建设主合同加补充协议。还能直接从卡片「为此项目建合同」，不用回头翻项目下拉框。

![项目视图](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/8.webp)

### 4. 一份合同，六个维度看透

点开合同，右侧抽屉分「基本信息 / 文件与版本 / 履约节点 / 收付款 / 审批 / 生命周期日志」六个 Tab。基本的方向、类型、金额、起止日、自动续约、终止条件都在第一屏。

![合同详情-基本信息](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/4.webp)

几个自己用着顺手的细节：

- **文件与版本**：正文可标记，换版自动升 v1、v2，历史版本留着，每次说明谁、何时、换了哪一版。下载预览都记日志。
- **履约节点**：交付、验收、质保这些里程碑走时间轴，实际完成晚于计划自动标"逾期"。
- **轻量审批**：草稿提交进"审批中"，管理员通过或驳回（驳回必须写意见）。金额小的直接签，达到阈值（比如 ≥10 万一级、≥50 万二级）才走相应审批。
- **生命周期日志**：创建、改字段、状态流转、换文件、查看、下载、收付款登记、归档——只追加不能改，交接审计扯皮的时候翻日志比翻聊天记录靠谱。

### 5. 收付款：计划和实际分开记，差额一眼看到

很多台账管到签完合同就断了，钱的事没人跟。这里把「收付款计划」和「实际流水」分开：计划拆成期次（首付、进度款、尾款），实际逐笔登记到账，每期自动算差额，没收到、只收一部分的高亮提醒。

![合同详情-收付款](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/5.webp)

合同维度看合同金额、计划合计、已收已付和余额；看板汇总应收未收、应付未付和回款率。最关键的是——计划归计划，实际归实际，对不上就标出来，不用月底再拉表算。

### 6. 看板与到期提醒，风险提前看见

顶部 KPI 之外，看板页有对内对外占比环图、状态分布柱状图，再加「即将到期 Top 10」和「已过期未处理 Top 10」两张清单。台账行直接标"5 天后到期""已过期 20 天"，提醒窗口（30/15/7 天）可配。自动续约和终止条件备注也一起显示，帮着判断要不要处理。

![看板统计](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/7.webp)

### 7. 设置灵活，换家公司也能用

系统设置里有合同类型字典（按方向过滤，被引用的不能删）、编号前缀、金额口径、审批阈值、提醒天数、归档策略、脱敏规则和登录密码修改。换个公司用不用改代码，改设置就行。

![系统设置](https://zhouqm.oss-cn-beijing.aliyuncs.com/zybkpro/1120/6.webp)

## 多端协同：电脑管台账，手机查合同

桌面端、浏览器、手机读写的是同一份数据。公司里选一台常开的电脑当主机，数据存本机 SQLite；需要给别人看时，在设置里一键开局域网服务，同一 Wi-Fi 下手机扫码进来就行。

电脑走 IPC、手机 H5 走 HTTP，最终都进同一套 core.dispatch，写库只有主机一个点，不会出现好几份数据库各改各的。手机端可以查看合同、登记收付款，也能开「只读」防止现场误改。

## 它解决什么问题

合同一多，「谁签的、在哪、什么时候到期、钱收没收回」就容易糊。这套系统针对办公室里最常见的四类麻烦：

| 痛点 | 现状 | 合同管理系统怎么做 |
|------|------|------------------|
| 合同散落 | 销售合同在销售那、采购合同在项目那，扫描件在网盘微信 | 对内对外一本台账，方向字段区分，按项目一眼看全 |
| 对内对外对不上 | 一个项目既有销售又有采购，关系全靠人记 | 项目卡片挂多份合同，主合同 / 补充协议有层级 |
| 到期回款靠人盯 | 续约、回款没人提醒，过期了才发现 | 到期窗口可配，台账行标天数，看板列 Top10 清单 |
| 改过就忘 | 谁改了金额、谁换了文件，交接审计翻聊天记录 | 全生命周期日志，查看下载都留痕，只追加不可改 |

## 谁适合用

- 同时跑几个项目、每个项目既有销售合同又有采购/外包合同的中小企业；
- 合同散在个人电脑、网盘、微信，想统一台账的商务、行政、项目部门；
- 需要跟踪回款进度、到期续约，又不想上重型 ERP / 法务系统的团队；
- 希望数据落在自己电脑或内网、不强制上公有云的组织；
- 能接受「选一台相对常开的电脑当主机」这种轻量部署。

不适合期待超大型多组织权限体系、公网多租户 SaaS、复杂法务知识库或 BPM 流程引擎的场景。

## 下载与开始使用

官网按系统提供对应版本：

- **Windows**：绿色版 ZIP，解压后双击 CONTRACT-AMS.exe 即可运行，免安装。
- **macOS（Apple Silicon / M 系列）**：arm64 的 ZIP，解压后先跑一次随包的 mac-first-run.sh 解除隔离，再双击 .app。
- **macOS（Intel）**：x64 的 ZIP，解压即用。

上手流程：解压桌面端 → 用 admin / 123456 登录（登录后可在设置里改密码）→ 先建项目和相对方，再录合同 → 需要多人看时开局域网服务、手机扫码进 H5 → 日常在桌面维护台账、登记收付款、看日志和看板。
