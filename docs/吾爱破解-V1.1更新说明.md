## 一、这次主要改了什么（先看这 6 条）

1. **附件预览/下载修好了** —— V1.0 里点附件经常没反应，这次桌面端改成走系统默认程序打开、也能另存为；局域网/手机端支持断点续传，文件被删了会明确提示"文件不存在"，不再默不作声。
2. **台账和看板可以按项目下钻** —— 项目多、一个项目挂十几份合同的，顶部选项目即可只看这一家的 KPI、图表和清单；台账还能切成"按项目分组"的二级视图。
3. **在签金额分成收入和支出了** —— 之前"在签金额"把销售和采购混在一起，KPI 看着不准。现在拆成"在签收入（对外）"和"在签支出（对内）"，净额可自己选开不开。
4. **补充协议一键创建** —— 从主合同详情或台账点一下，自动继承方向/类型/项目/相对方/负责人，编号按 `主编号-1`、`主编号-2` 自动排，不用手工编号和重复录入。
5. **发票登记上线** —— 合同详情多了"发票"Tab，还有全局发票视图。开票/收票都能记，税额自动算，作废要填原因且不计入合计，总算能把"合同 → 票 → 款"这条链对上。
6. **备份能真正导出 zip 了** —— 点"备份"直接弹另存为，选个位置就把数据库+配置+全部附件打包带走；还能设每天/每周定时备份到指定目录，滚动保留最近 N 份。

## 二、详细更新清单

### P0 · 大家反馈最集中的问题（必修）

**① 附件预览 / 下载（评论 #41、#68 多人复现）**

- 桌面端：点"预览"调用系统默认程序打开，点"下载"弹另存为对话框，成功失败都有提示并记日志；
- 手机 / 浏览器端：支持 HTTP Range 断点续传，PDF 等大文件加载更稳；
- 附件文件被挪走或删掉时会提示"文件不存在"，不再点了没反应。

![按项目下钻](在这里替换为按项目分组截图地址)

**② 按项目看台账 / 看板（评论 #57）**

- 顶部加项目筛选，选中的项目会联动 KPI、图表、即将到期 / 已过期 Top10；
- 台账可切"按项目分组"，每个项目一行汇总（对外/对内金额、应收未收、应付未付），展开看明细，展开状态本机记住；
- 项目视图卡片加了"在台账中查看 / 在看板中查看"快捷入口，不用再回下拉框翻。

**③ 在签金额区分收入 / 支出（评论 #62）**

- KPI 拆成"在签收入（对外）"和"在签支出（对内）"，都带金额口径说明；
- 看板环图按收支口径重做，"在签净额"可在设置里选择显示。

**④ 补充协议一键创建（评论 #57）**

- 主合同详情和台账工具栏都有入口，新建时自动继承主合同的项目、相对方、我方主体、币种、负责人等字段；
- 编号自动排成 `{主合同编号}-1`、`-2`，全局唯一不重复；主合同详情里能看到挂了几份补充协议；
- 有补充协议的主合同不允许直接删除，避免误删 links 断掉。

### P1 · 实用功能补齐

**⑤ 发票登记（之前答应 V1.1 的核心）**

- 合同详情新增"发票"Tab，顶部导航新增全局"发票"视图；
- 支持开票/收票、专票/普票/电子票，填了金额和税率自动算税额；
- 作废必须填原因，作废的票不计入合计；
- 合同维度显示"已开票 / 已收票 / 合同金额 − 已开票"，形成最小闭环。

![发票登记](在这里替换为发票界面截图地址)

**⑥ 税金、费用分类、字段可改名（评论 #102）**

- 合同表单加不含税金额、税额、税率三者联动计算；
- "费用分类"字典可自己维护（合同类型偏法务，费用分类偏财务口径）；
- 字段显示名可配置——比如你们习惯把"相对方"叫"客户"，改完列表表头和导出表头一起变，数据库字段名不受影响。

**⑦ 收付款期次模板 + 违约金/罚息（评论 #95、#83）**

- 收付款计划支持按模板批量生成：一次性、首付+尾款（默认 30/70）、按季度，省得一页页手填；
- 计划和流水新增"性质"字段：合同款 / 违约金 / 迟延履行利息 / 资金占用利息 / 其他；
- 罚息这类不计入回款率，看板单独汇总，不会把"钱收回来"的指标污染掉。

**⑧ 大附件与备份（评论 #57、#69）**

- 单文件上传上限从 50MB 提到默认 200MB，设置里最高可调到 300MB；超过 1MB 的文件按 MB 显示大小，上传时有状态提示；
- 备份重构：点"备份"弹另存为，把数据库 + 配置 + 全部附件打成一个 zip 让你带走；设置里可配每日/每周定时备份到指定目录，滚动保留最近 N 份，配合网盘同步就是异地备份；
- 导入页常驻"下载模板"按钮，导入失败的每一行都能复制出来，方便改完重导。

**⑨ 其他细节**

- 顶部栏右上角加了刷新按钮，改完东西不用重开窗口；
- 设置里新增"数据管理"页，可以手动备份、也能清空本地业务数据（二次确认 + 输入"清空"才执行；账号和系统设置保留）；
- 补充协议、导入导出等一批顺手的小优化。

## 三、升级说明（重要）

**从 V1.0 升级不用导数据、不用重装**，下载 V1.1 覆盖原目录即可：

- 启动时会自动做幂等迁移，补齐税金 / 分类字段、发票相关的表、收付款的"性质"字段；
- 老数据里原来的"金额"统一当作价税合计看待，不会算错；
- 内置账号（admin / biz / pm / finance）和原有密码、合同条款、附件都保留。

⚠️ 覆盖前建议先备份一份数据（设置 → 数据管理 → 备份），以防万一。

**关于数据恢复**：如果哪天清空了数据，用之前导出的台账 Excel 重新导入就能恢复——V1.1 导入时会自动按名称重建相对方和项目档案，不需要先手工建档。
