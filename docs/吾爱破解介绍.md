资产管理系统
核心功能
1. 一屏看清家底
深色运维看板：顶部是 KPI 汇总（在册、在用、闲置、故障、报废、超五年设备），中间是分类占比环图、状态柱状图和搜索词云，下面是完整资产台账。打开第一屏就知道有多少设备、分别是什么状态。

桌面端资产看板

2. 资产信息，一处改完
台账里双击任意一行即可编辑：资产编号、名称、分类、型号、购入日期、价格、使用人、状态、序列号、备注，还能挂最多 4 张图片 和 3 个附件。该换人的换人，该标故障的标故障，不用再另开一张表。

资产新增/编辑弹窗

3. 全生命周期留痕
这是让人安心的细节：导入、换人、改状态、传文件……每一次变更都按时间轴记录。谁在什么时候动过什么，随时能翻回去查。交接、审计、扯皮的时候，翻日志比翻聊天记录靠谱得多。

全生命周期日志时间轴

4. Excel 导入导出
从旧台账迁过来成本低，日常也能导出成表。资产分类与编号前缀都可以自定义（如台式机 PC、笔记本 NB），新资产按规则自动出号。

5. 本地 SQLite，数据在手
数据存在自己电脑的单文件 SQLite 里，程序也在本地跑。断网、内网隔离环境照样能用；拷走数据目录就是备份，关掉服务不占公网资源。不注册账号，不上传资产信息到第三方。

6. 手机 H5 现场盘点
主机开启局域网服务后，手机扫码连上就能按状态筛选、卡片式翻设备，看型号、序列号、价格、使用人；图片可放大，附件可下载。现场改状态或使用人，保存即写回同一份库并记入日志。可开启「H5 只读」，防止现场误改。

手机 H5 资产盘点

多端协同：电脑管账，手机下场
这是 IT-AMS 最「落地」的能力。桌面端、浏览器、手机读写的是同一份数据。

局域网服务设置

三步走通现场协作：

设置里点一下启动 — 默认端口 8787，自动生成访问地址、二维码和口令，可选「H5 只读」。
手机扫码连上 — 按状态筛选、卡片翻设备，看型号、序列号、价格、使用人，图片放大、附件下载。
现场改，当场落库 — 改状态或使用人，保存即写回同一库并记进日志。关掉服务就不占公网资源。
局域网中同时只有一个主机写库，避免多份 SQLite 分叉；桌面窗口通过 IPC、H5 / Web 通过 HTTP，最终都进入同一套业务内核。

技术架构
唯一写库点在主机，API 只有一套。 Electron 桌面端同时充当数据主机；需要协作时，主进程里一键拉起局域网服务。业务内核与传输分离——端可以有多份，数据只有一份。

Electron Main（数据主机）：IPC → core.dispatch；sql.js → itams.sqlite；LanServer → 0.0.0.0:8787
桌面渲染进程：Vue3，本机窗口走 IPC、免鉴权
手机 H5 / Web：同网段走 HTTP，口令 Token 访问
主要技术栈：Electron 33、Vue 3、Vite 6、ECharts 5、sql.js（SQLite WASM）、SheetJS、qrcode。

选 sql.js 而不是原生 SQLite，核心收益是绿色版解压即跑，免去 Electron ABI / 重建模块的坑。产品定位是办公室中小台账，不做高并发 OLTP。

谁适合用
设备几十到几百台，商业 ITSM / CMDB 又太重、太贵的团队；
希望数据落在自己电脑或内网，不强制上公有云的组织；
行政、IT、库管经常要现场核对，需要手机端配合的场景；
能接受「选一台相对常开的电脑当主机」这种轻量部署。
不适合期待超大型多组织权限体系、公网多租户 SaaS、7×24 无人值守机房级运维的场景。

下载与开始使用
官网按系统提供对应版本：

Windows：绿色版 ZIP，解压后双击 IT-AMS.exe 即可运行，免安装。
