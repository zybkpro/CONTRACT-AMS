核心功能

1. 一屏看清合同家底

深色台账看板：顶部 8 个 KPI（合同总数、在签金额、履约中、本月到期、已过期未处理、应收未收、应付未付、回款率），下面是可以按方向、状态、项目筛选的合同列表。打开第一屏就知道公司现在有多少合同、多少钱在签、哪几份快到期、还有多少款没收回来。

[图片:合同台账主界面]

2. 对内对外，一本台账管完

这是当初做它的主要理由。很多公司销售合同在销售手里、采购外包合同在项目手里，文件散在网盘和微信，对内对外根本对不上。这套系统里，对内（采购、外包、劳动补充）和对外（销售、框架、NDA）共用一张表，只用「方向 / 类型」区分。新建时编号自动生成——对外 XS20260001、对内 CG20260001，不用手工编号。

[图片:新增合同表单]

台账里点任意一行就能编辑，字段变更自动写日志，谁在什么时候把金额从多少改到多少，翻记录就行，不用另外开表对。

[图片:编辑合同表单]

3. 按项目看合同，一项目多合同不糊涂

项目视图用卡片列出每个项目挂了几份合同、合同总金额、起止时间。比如"智慧园区一期"下面挂着 4 份：软件外包、硬件采购、平台建设主合同加补充协议。还能直接从卡片「为此项目建合同」，不用回头翻项目下拉框。

[图片:项目视图]

4. 一份合同，六个维度看透

点开合同，右侧抽屉分「基本信息 / 文件与版本 / 履约节点 / 收付款 / 审批 / 生命周期日志」六个 Tab。基本的方向、类型、金额、起止日、自动续约、终止条件都在第一屏。

[图片:合同详情-基本信息]

几个自己用着顺手的细节：

• 文件与版本：正文可标记，换版自动升 v1、v2，历史版本留着，每次说明谁、何时、换了哪一版。下载预览都记日志。

• 履约节点：交付、验收、质保这些里程碑走时间轴，实际完成晚于计划自动标"逾期"。

• 轻量审批：草稿提交进"审批中"，管理员通过或驳回（驳回必须写意见）。金额小的直接签，达到阈值（比如 ≥10 万一级、≥50 万二级）才走相应审批。

• 生命周期日志：创建、改字段、状态流转、换文件、查看、下载、收付款登记、归档——只追加不能改，交接审计扯皮的时候翻日志比翻聊天记录靠谱。

5. 收付款：计划和实际分开记，差额一眼看到

很多台账管到签完合同就断了，钱的事没人跟。这里把「收付款计划」和「实际流水」分开：计划拆成期次（首付、进度款、尾款），实际逐笔登记到账，每期自动算差额，没收到、只收一部分的高亮提醒。

[图片:合同详情-收付款]

合同维度看合同金额、计划合计、已收已付和余额；看板汇总应收未收、应付未付和回款率。最关键的是——计划归计划，实际归实际，对不上就标出来，不用月底再拉表算。

6. 看板与到期提醒，风险提前看见

顶部 KPI 之外，看板页有对内对外占比环图、状态分布柱状图，再加「即将到期 Top 10」和「已过期未处理 Top 10」两张清单。台账行直接标"5 天后到期""已过期 20 天"，提醒窗口（30/15/7 天）可配。自动续约和终止条件备注也一起显示，帮着判断要不要处理。

[图片:看板统计]

7. 设置灵活，换家公司也能用

系统设置里有合同类型字典（按方向过滤，被引用的不能删）、编号前缀、金额口径、审批阈值、提醒天数、归档策略、脱敏规则和登录密码修改。换个公司用不用改代码，改设置就行。

[图片:系统设置]
